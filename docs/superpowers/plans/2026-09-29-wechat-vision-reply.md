## 验证边界

- Windows 数据库新消息读取及 AI 生成由运行日志验证；交替测试覆盖 GUI 定位、发送和数据库回读，不能当成两个账号全部收消息端到端场景的测试报告。
- 当前实机结果属于 Windows 微信 4.1.15.13；其他版本、设备与窗口布局需重新运行探针。
- macOS 代码和模拟测试已同步，Mac 实机验证尚未执行。
- Windows 无会话 ID 手动发送与 macOS 发送后确认保留兼容路径，后续若调整必须另做验证。

## 再次实机检查

运行 `backend/live_reply_probe_windows.py --help` 查看参数。默认只核对本地联系人；`--allow-vision` 上传定位截图，`--send` 发送三轮测试文本，`--alternate-with` 增加第二个联系人。开启前核对对象并取得授权，测试期间避免切换窗口。

测试报告写入 `data/`，不得提交。正式启动前关闭旧 EXE，保留安装目录中的 `_internal`，在 Web 设置自己的白名单。
